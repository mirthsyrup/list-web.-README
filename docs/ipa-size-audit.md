# APK / IPA 2.8.5: совпадение с сайтом и размер

Проверены опубликованный ZIP сайта и оба файла из указанной папки Google Drive.

| Файл | Размер в байтах | МБ (1 000 000 байт) |
| --- | ---: | ---: |
| APK 2.8.5 | 12 854 162 | 12,85 |
| Оригинальная IPA 2.8.5 | 22 032 273 | 22,03 |
| Компактная IPA 2.8.5 | 12 485 033 | 12,49 |

Экономия: **9 547 240 байт, или 43,3%**. APK менять не требуется.

## Почему IPA была больше

Все 58 веб-файлов APK и IPA совпадают с содержимым сайта 2.8.5 побайтно.
У iOS дополнительно есть `web/ios-entry.html`: нативная оболочка открывает эту
самодостаточную страницу. В неё встроены код, каталоги, стили и изображения
фона. Она занимает 36 082 207 байт без сжатия и 9 691 003 байта внутри IPA.
Рядом были повторно упакованы отдельные копии уже встроенного содержимого.

## Что изменено

Из копии пакета убраны 38 отдельных JS-файлов, две таблицы стилей, четыре
фоновых JPEG, а также неиспользуемые нативной оболочкой веб-страница `index.html`
и service worker. Содержимое каждого JS и CSS сверено с соответствующей
встроенной копией, байты фоновых JPEG — с data URI в странице.

`ios-entry.html`, исполняемый файл `List`, его ad-hoc подпись, `Info.plist`,
идентификатор приложения `ru.seriylist.app`, версия 2.8.5/284, все иконки,
манифест и юридические материалы сохранены побайтно. Права файлов также
сохранены. Настройки и местоположение сохранений не менялись.

## Проверки и ограничения

- Целостность ZIP/CRC и побайтное совпадение всех 29 оставшихся записей.
- Совпадение веб-файлов обоих оригинальных пакетов с сайтом.
- Запуск оригинальной и компактной страниц в Chromium с заглушками iOS-моста.
- Все 16 569 записей справочника, все категории, поиск и карточка заклинания.
- Расчёт ОЗ/защиты, получение урона, сохранение после перезагрузки и экспорт.
- Переключение темы, фоновые текстуры при ширине 390 и 1280, лицензии.
- Запросы к интернету запрещены тестовым маршрутизатором; файлы пакета
  обслуживались локальным HTTP-сервером.

Политика управляемого браузера блокирует `file://`, поэтому проверка выполнена
через локальный HTTP. Реальные WKWebView, системное сохранение/экспорт и
установка/обновление на физическом iPhone здесь не проверены. Рабочая страница
и нативная оболочка не изменены, что ограничивает риск упаковкой ресурсов.

Оригинальная IPA не содержит provisioning-профиля и `_CodeSignature/CodeResources`;
исполняемый файл имеет только ad-hoc CodeDirectory без resource special slots.
Для установки использовать тот же процесс sideload/переподписания, что оригинал.
Скрипт не переносит эту оптимизацию на обычные подписанные IPA без штатной сборки.

Дополнительная проверка SHA-256 страниц обнаружила, что linker ad-hoc подпись
оригинального исполняемого файла уже не соответствует двум страницам (6 и 7).
В компактной копии результат тот же: бинарный файл и подпись не менялись.
Это ещё одна причина устанавливать обе IPA через штатное переподписание,
а не считать исходный архив готовым подписанным App Store-приложением.

Машинные отчёты: [упаковка](ipa-size-audit.json),
[браузерные сценарии](ipa-browser-checks.json).

## Воспроизведение

```sh
python3 scripts/optimize_ipa.py original.ipa out/compact.ipa
python3 -m zipfile -e original.ipa out/original
python3 -m zipfile -e out/compact.ipa out/compact
# Нужны Playwright и Chromium; LIST_CHROME выбирает путь к Chromium.
node scripts/check_ipa.cjs out/original out/compact
```

Установка Playwright для ручной проверки: `npm install --no-save playwright`.
Эта проверка не включена в обычный `npm test`, поскольку требует обоих IPA.
