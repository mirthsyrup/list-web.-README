# Повышение уровня

«Just a random fanfare» — Spring Spring / Julie Damsgaard.

Источник: https://opengameart.org/content/just-a-random-fanfare

Лицензия CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/

Исходная запись: `assets/sounds/level-up.ogg` (fanfare_0.ogg).
Владелец выбрал вариант 1 из длинной подборки. Фанфара используется целиком,
без обрезки музыкальной фразы и без дополнительных звуковых слоёв.
Для синхронного офлайн-воспроизведения встроена PCM-копия: моно, 22050 Гц,
16 бит. Конвертер: `scripts/build_level_fanfare.py`.
