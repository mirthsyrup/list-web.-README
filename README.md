# Лист персонажа · Pathfinder 2e Remaster

Русский лист персонажа: создание героя, расчёт характеристик, заклинания,
инвентарь, справочник правил, локальные сохранения и резервные копии.

**Версия сайта в этой ветке: 2.9.11.** Сайт опубликован по адресу
https://mirthsyrup.github.io/list-web.-README/.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `site/` | Распакованный актуальный код и данные; редактировать здесь |
| `index.html` | Публичный загрузчик GitHub Pages |
| `list-site-2.9.11.zip` | Архив, который сейчас загружает публичный сайт |
| `tests/` | Актуальные проверки правил, сохранений, интерфейса и ZIP-загрузчика |
| `scripts/` | Проверка соответствия исходников релизу и оптимизация IPA |
| `docs/` | Отчёт о приложениях и правила выпуска |
| `archive/site-bundles/` | Предыдущие архивы сайта |
| `archive/app-sources/` | Старые исходники веб-части приложения 2.7.11/2.7.12 |
| `archive/verification-*/` | Исторические отчёты и проверки |

Исходники `site/` и релизный ZIP собираются из одной версии. Исторические
архивы сохранены в `archive/`; история Git не переписывается.

## Запуск и проверка

Нужны Python 3 и Node.js 22 или новее.

```sh
npm ci
npm test
npm run check:release
npm run serve
```

Открыть http://localhost:8080. `npm test` проверяет также публичный загрузчик,
который открывает актуальный ZIP. Тесты DOM используют JSDOM, а не настоящий
iPhone; они не измеряют плавность анимаций на устройстве.

## Приложения

Актуальные APK/IPA находятся в [папке Google Drive](https://drive.google.com/drive/folders/14rxQ7_bHaPrFeHiKD163ut0c-q7D7wHL).
APK 2.9.6 подписана тем же ключом, что предыдущие версии. Компактная IPA
устанавливается через привычный процесс sideload-подписи. Архивы сайта и
пакеты приложений собраны из одних исходников.
IPA 2.9.1 обновляет нативную оболочку: теперь вибрация доступна и на iPhone.
В версии 2.9.2 сайт, APK и IPA получили одинаковые исправления визуального отклика.
Архивы исходников приложения
2.7.11/2.7.12 в `archive/` — более старые версии, не источник текущего релиза.

Исходники и воспроизводимая сборка iOS-оболочки находятся в
[native/ios](native/ios/README.md). Для Android сохраняются проверяемые патчи
исходной оболочки; полного Android-проекта и ключей подписания в Git нет.

Подробности: [аудит IPA](docs/ipa-size-audit.md) и [выпуск версий](docs/releases.md).

## Отклик действий 2.9.0

Урон, лечение и броски получили короткие синтезированные звуки, работающие
без сети. На здоровье появляется фактическая величина изменения; критический
успех и провал подсвечивают компас только после сравнения с КС по правилам.
В настройках отдельно отключаются звук, вибрация и визуальный отклик; есть
громкость. Уменьшение движения сохраняет текстовые подписи.

Android-оболочка поддерживает системный тактильный отклик и его настройки.
В IPA 2.9.1 добавлен мост к системным эффектам UIKit: на iPhone работают
звук, визуальный и тактильный отклик. Беззвучный режим iOS не обходится.

## Визуальный отклик 2.9.2

Исправлено повторное появление цифры здоровья в конце анимации. Фактическая
величина урона (включая временные ОЗ) или лечения показывается одним числом
без знака, единиц и плашки: красным или зелёным. Cinzel 800 (SIL OFL 1.1),
27 px вместо 18 px; случайный вылет на 76–108 px затухает за одну секунду.
Для уменьшения движения остаётся неподвижное число.

Критический успех окрашивает компас в золото с кольцом и расходящимися искрами;
критический провал — в красный, с разлетающимися фрагментами и оседающими искрами.
Число броска остаётся в центре. В настройках удалены кнопки проб и демонстрационный
блок. Звуковой движок сохранён: новые записи выбираются отдельно после прослушивания.

Проверены публичный ZIP, фактическая веб-часть APK/IPA и сохранение нативных мостов.
Тесты браузера проверяют отсутствие повторного мигания по кадрам, цвет компаса,
отключение эффектов, уменьшение движения и реальные изменения ОЗ.

## Выбранные звуки и критические броски 2.9.6

Встроены ровно выбранные записи: урон D1/D2, лечение H10/H6,
критический успех S16 и провал F1. Порог — 20% максимальных ОЗ,
включая ровно 20%. Для лечения используется фактически восстановленная
величина, для урона — полученный урон после сопротивлений и слабостей.
Записи работают без сети через PCM/WebAudio; никаких дополнительных фоновых
слоёв. Генератор: `python3 scripts/build_feedback_samples.py` (требуется FFmpeg).

Без КС максимум и единица теперь включают критический отклик на к4/к6/к8/к10/
к12/к20/к100; у группы костей — только все максимумы или все единицы.
С указанной КС приоритет сохраняется за степенью результата Pathfinder.
Во всплывающем журнале бросков доступна кнопка «Бросить кости».
После первоначальной анимации золотая или красная печать сохраняется
неподвижной до нового броска; фоновых циклов анимации нет.

## Один сайт, два дизайна · 2.9.8

В настройках основного [сайта](https://mirthsyrup.github.io/list-web.-README/)
доступны современный и средневековый дизайн. Светлая и тёмная темы выбираются
отдельно; прежний выбор для каждого дизайна сохраняется.

При смене дизайна сначала записываются персонажи и черновик, затем интерфейс
перезагружается на том же адресе. Выбранный раздел, черновик создания героя и
окно настроек восстанавливаются. При ошибке сохранения переключение отменяется.
Данные персонажей, инвентарь, магия, синхронизация и настройки отклика общие.

Единственный код приложения находится в `site/app.js`; средневековые стили и
графика — в `site/designs/fantasy/`. Стили ограничены `data-design="fantasy"`
и не меняют современное оформление. `/fantasy/` перенаправляет на основной сайт
с выбором средневекового дизайна; старые графические ресурсы оставлены доступными.
Публичный ZIP содержит оба оформления, поэтому переключение работает без сети
после первой полной загрузки и установки service worker.

Перенос старых `fantasy-list-*` из версии 2.9.7 сохранён: при конфликте остаются
обе копии персонажа, исходные записи не удаляются. Перенос между устройствами
по-прежнему требует экспорта/импорта или настроенной синхронизации.

Перед сборкой ZIP после изменения файлов/версии запускать
`python3 scripts/build_offline.py`. Для проверки из корня репозитория:
`python3 -m http.server 8080`, затем
`node scripts/check_versions_browser.cjs http://127.0.0.1:8080` (Playwright/Chromium).
Проверяются все четыре оформления, реальная перезагрузка, сохранность библиотеки
и черновика, ошибка записи, старый URL и переключение без сети.
APK/IPA из предыдущего выпуска остаются на версии 2.9.6; этот выпуск меняет сайт.

В 2.9.9 знак кости на стартовом экране средневекового дизайна получил фактуру
матового серебра. Убраны остаточные розовые обводки поиска, состояний и эффектов.

В 2.9.10 подписи выбора дизайна выровнены по центру, устранён выступ
факела за ширину экрана и отключено оттягивание средневековой страницы
за края. Вертикальная прокрутка и локальные горизонтальные списки сохранены.

В 2.9.11 только для средневекового дизайна убрана дублирующая линия
под именем персонажа. Кнопки настроек прозрачны и используют общий фон
панели; текущий дизайн отмечен подчёркиванием.
Строки с флажками получили фактуру пергамента, значки уровней в списках — кожи.
