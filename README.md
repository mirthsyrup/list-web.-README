# Лист персонажа · Pathfinder 2e Remaster

Русский лист персонажа: создание героя, расчёт характеристик, заклинания,
инвентарь, справочник правил, локальные сохранения и резервные копии.

**Версия в этой ветке: 2.8.6.** Сайт опубликован по адресу
https://mirthsyrup.github.io/list-web.-README/.

## Где что находится

| Путь | Назначение |
| --- | --- |
| `site/` | Распакованный актуальный код и данные; редактировать здесь |
| `index.html` | Публичный загрузчик GitHub Pages |
| `list-site-2.8.6.zip` | Архив, который сейчас загружает публичный сайт |
| `tests/` | Актуальные проверки правил, сохранений, интерфейса и ZIP-загрузчика |
| `scripts/` | Проверка соответствия исходников релизу и оптимизация IPA |
| `docs/` | Отчёт о приложениях и правила выпуска |
| `archive/site-bundles/` | Предыдущие архивы сайта |
| `archive/app-sources/` | Старые исходники веб-части приложения 2.7.11/2.7.12 |
| `archive/verification-*/` | Исторические отчёты и проверки |

Исходники `site/` и релизный ZIP собираются из одной версии. Исторические
архивы сохранены в `archive/`; история Git не переписывается.

## Запуск и проверка

Нужны Python 3 и Node.js 22 или новее.

```sh
npm ci
npm test
npm run check:release
npm run serve
```

Открыть http://localhost:8080. `npm test` проверяет также публичный загрузчик,
который открывает актуальный ZIP. Тесты DOM используют JSDOM, а не настоящий
iPhone; они не измеряют плавность анимаций на устройстве.

## Приложения

APK/IPA 2.8.5 находятся в [папке Google Drive](https://drive.google.com/drive/folders/14rxQ7_bHaPrFeHiKD163ut0c-q7D7wHL).
Исходные пакеты 2.8.5 сохранены. Для версии 2.8.6 подготовлены новые
веб-файлы и инструменты упаковки; Android требует прежнего ключа подписи.
Архивы исходников приложения
2.7.11/2.7.12 в `archive/` — более старые версии, не источник текущего релиза.

Полный исходный проект нативных оболочек Android/iOS и ключи подписания в этом
репозитории отсутствуют. Нельзя считать скрипты переупаковки старых APK/IPA
полноценной сборкой нативного приложения.

Подробности: [аудит IPA](docs/ipa-size-audit.md) и [выпуск версий](docs/releases.md).

## Обновление плавности 2.8.6

Оптимизировано сворачивание групп и целых блоков умений. Для iOS добавлен
допуск ProMotion; для Android подготовлен запрос самого быстрого режима
с прежним разрешением. [Описание и проверки](docs/smoothness-2.8.6.md).

[Компактная IPA 2.8.6](https://drive.google.com/file/d/1uvyMqrEa9FF3nuHehJjCilbx28o35gJz/view)
устанавливается через прежний процесс подписи sideload.
[Android-пакет для подписи](https://drive.google.com/file/d/1mpho22c_E6GVmBN4WPubKC57HiU7NPPh/view)
содержит unsigned APK: готовое обновление требует того же ключа, что 2.8.5.
Физические устройства не проверялись; гарантии постоянных 120 FPS нет.
