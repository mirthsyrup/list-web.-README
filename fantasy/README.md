# Кожа и пергамент

Средневековое оформление листа 2.9.7. Графика, тема и `app.js` находятся в
`fantasy/`; правила, каталоги, хранилище, фильтры, эффекты и прочие общие модули
подключаются из `site/`.

Обе версии используют ключи сохранений и настроек `list-*`. Старые
`fantasy-list-*` переносятся один раз без удаления исходных записей; конфликтующие
персонажи сохраняются отдельными копиями. Только тема остаётся отдельной
(`fantasy-list-theme`). При первом запуске демонстрационный лист не создаётся.
Быстрый доступ, подсказки и список персонажей совпадают по поведению с простой
версией; материалы и рисованные значки сохранены.

После первой загрузки и установки service worker версия работает без сети.
`sw.js` создаётся `python3 scripts/build_offline.py`; его кэш независим от кэшей
простого сайта и публичного ZIP-загрузчика. APK/IPA этим изменением не обновляются.
