# Старый адрес средневекового оформления

`/fantasy/` перенаправляет на основной сайт с параметром `?design=fantasy`.
Параметр сохраняется как выбор дизайна и убирается из адреса; дальнейшее
переключение выполняется в настройках основного приложения.

Код приложения находится в `site/app.js`, оба дизайна входят в публичный ZIP.
Действующие средневековые ресурсы — в `site/designs/fantasy/`; старые `assets/`
оставлены для совместимости с прежними адресами. Здесь нет отдельного приложения.

Прежний выбор светлой/тёмной темы хранится в `fantasy-list-theme`.
Персонажи и прочие настройки остаются общими (`list-*`); перенос старых листов
из отдельных хранилищ сохраняется. APK/IPA этим выпуском не обновляются.
